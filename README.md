# Personal Portfolio Website 🌐

## 📌 About the Project
This is a beginner-friendly personal portfolio website developed using **HTML** and **CSS**. It showcases personal information, academic details, technical skills, projects, and contact information through a simple multi-page website.

The project was created to practice the fundamentals of front-end web development and understand how HTML and CSS work together to build and style web pages.

---

## ✨ Features
* **Home Page:** Introduction and overview of the website.
* **About Page:** Personal and academic information.
* **Contact Page:** Contact details displayed in a table.
* **Navigation:** Clean links to move seamlessly between website pages.
* **CSS Styling:** Background gradients, custom colors, stylized tables, shadows, and hover effects.
* **Multi-page Structure:** Organized with separate HTML and CSS files for different pages.

---

## 🛠️ Technologies Used
* **HTML5**
* **CSS3**

## 🚀 How to Run the Project
1. **Clone or download** this repository to your local machine.
2. **Open** the project folder.
3. Launch `Website.html` in your preferred web browser.
4. Use the navigation links to explore the different pages.
* *Note: You do not need any additional libraries, servers, or installations to run this project.*
